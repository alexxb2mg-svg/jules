# Consignes d'expression des aménagements

Un fichier `<identifiant>.md` par aménagement. Quand le profil de l'élève contient
`amenagements: [<identifiant>, ...]`, le **corps** de chaque fichier (après l'en-tête YAML) est
ajouté au prompt dans un bloc au titre neutre, « Expression adaptée ».

Règles (docs/spec/ADAPTATIONS.md, EX-004 et EX-005) :

- l'identifiant et le nom de l'aménagement ne sont jamais envoyés au modèle : seul le corps part ;
- le corps décrit une façon de s'exprimer (longueur des phrases, découpage...), jamais un nom de
  trouble ni un diagnostic ;
- un identifiant absent de ce dossier est ignoré (message dans le journal).

Contenu provisoire : les valeurs et la liste des aménagements sont fixées au lot 2, à relire par
un professionnel.
